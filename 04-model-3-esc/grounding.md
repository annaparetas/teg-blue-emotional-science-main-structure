## What kind of claim each part is

| Part of the model | Level | Note |
| --- | --- | --- |
| Detection, mobilisation and recovery within an event | Established evidence, drawn together | Emotion processes, autonomic and endocrine recruitment, interoception, action readiness, stress-response termination, physiological recovery, learning. |
| Persistence and updating | Established evidence, drawn together | Allostasis, perseverative cognition, state-dependent processing, reinforcement, habit, social buffering, context-dependent capacity restriction. |
| Relief and completion can diverge | Grounded synthesis | Immediate pressure can change without the condition, prediction or organisation updating. |
| The shared event spine and five hinges | TEG-Blue integration | Functional distinctions inside a recursive process. |
| Fluid Cycle and Chronic Cognitive-Override Cycle | TEG-Blue integration | The comparison and the seven override distinctions are grounded component by component in the files below. |
| Carryover as a decomposable set | TEG-Blue integration over established routes | Continuing conditions, uneven recovery, reconstruction, changed later recruitment, cumulative cost; see the recruitment, persistence and recovery bridge. |
| The shared event record | Architectural coupling interface | A recording discipline, not a claim that discrete time points exist. |
| Behaviour and harm | Separate evidence plane | No internal cycle configuration establishes intention, diagnosis, coercion or safety. |

Do not present the assembled cycle as an established mechanism because its
components are individually supported. Apply the Science Grounding Protocol
before strengthening any causal claim.

## Provenance

The two-cycle rebuild was prototyped, grounded and canonicalised between 22
and 23 August 2026 and named The Emotional–Somatic Cycle on 23 August,
replacing the earlier public label The Emotional Systems Cycle. The canon
page here absorbs the 23 August companion draft (old `foundation/24`), the
Model 3 sections of the core architecture decision, and the 27 August
summary from the former main structure. The shared event record was added
on 23 August 2026 to connect the three models through one changing event.
