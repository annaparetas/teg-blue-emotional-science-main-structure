# TEG-Blue Site Authority Rule

This repository is the canonical, navigable TEG-Blue site. It holds one canon
page per conceptual owner, the connected site structure and curated grounding
or working context needed to understand each concept.

The active development engine remains
`../inner-compass-nervous-system-organization-gradient/`. Its research,
owner reviews, experiments, branches and full provenance do not become site
authority merely because a file has been carried here.

Before editing:

1. identify the exact Anna-approved decision being transferred;
2. identify its conceptual owner and source in
   `../inner-compass-nervous-system-organization-gradient/`;
3. preserve the distinction among approved architecture, provisional ideas and
   open decisions;
4. label carried research, working notes and unresolved owner language as
   grounding, working or archived; never present them as settled canon;
5. do not infer behaviour, personality, diagnosis, morality or another
   person's internal organisation from emotion, access or Gradient Position;
6. preserve established emotion-family membership unless Anna explicitly
   reopens it;
7. keep one principal `index.html` page per major conceptual owner and use
   shared assets for navigation and presentation;
8. keep `STATUS.md` as the site control board and `GLOSSARY.md` as the site
   terminology authority;
9. treat `../teg-blue-emotional-science/` as migration history after this
   structure has been verified, not as a second active site.

After editing, verify local links, HTML structure, keyboard access, responsive
layout and Git scope. Commit this repository independently from the active
development engine.
