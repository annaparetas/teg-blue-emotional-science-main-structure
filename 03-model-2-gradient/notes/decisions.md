Connection: every Fluid position. Protection: Chronic X, A, A↔B, B, Z.

## 2026-08-23 · Return vocabulary reconciled; companion drafts written

Return follows the shared three-model definition: renewed availability of
more flexible, less defensively dominated and more restorative organisation.
Baseline re-access is a Gradient-specific description, not the definition of
Return. Nine terms fixed as not interchangeable: regulation, Return, baseline
re-access, completion, updating, recovery, restoration, repair, carryover.
Companion drafts for the Gradient and for Fluid and Chronic written.
