The site owns the revised dials, processing page, compatibility access route, static configuration snapshot, cycle page and shared event record. The carry manifest protects those files. Retired sources are identified by a fixed historical Git revision inside the transfer tooling; a later Engine redirect cannot replace their provenance.

Later Engine research requires a reviewed site edit and dated decision. The older “active Engine extension” wording in previous transfer records describes the former arrangement and is superseded by this decision. Underlying scientific questions keep their existing working status; approving this consolidation does not validate a diagnosis, score, personality interpretation or new causal claim.

The dials' stable anchors are `#bodily-access`, `#affective-sharing-access` and `#mentalizing-access`. Compatibility routes preserve these destinations and the `bia`, `asa`, `mau`, `position` and `reading` parameters when supplied. `assets/capacities.js` continues to own shared capacity state. Incoming URL settings initialise the page once; later independent edits persist and update the bookmark without losing position, reading or fragment context.

## Connected preview

Run `python3 scripts/serve.py` from the site repository. It serves the site at the root and mounts both sibling repositories under their folder names, so cross-repository links share one browser origin. Use this server for connected Engine/site review. A server exposing only the Engine folder cannot resolve sibling-site paths. No published domain is assumed by this decision.
