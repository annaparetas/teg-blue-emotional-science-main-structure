# Map register

One entry per diagram in the visual layer. What it is, what appears in it for
the first time, where that idea lives now, and what got dropped.

The last column is the one that stops work being redone. An idea that was tried
and set aside looks identical to an idea never had, unless someone wrote down
which it was.

Status: first pass, 2026-08-02. Entries marked **not seen** have not been
reviewed yet.

## What the visual layer became

The four modes drawn in the artwork are now stated in
`teg-blue-engine-2/source/THE-GRADIENT.md` as a compression layer over seven
Positions. Both naming systems fed into the Engine's, and they did not win
evenly.

| Map name | Written layer, April 2026 | Engine 2 Position |
| --- | --- | --- |
| CONNECTION / BELONGING | Safety & Openness | **A** Connection / Belonging |
| PROTECTION / DEFENSE | Threat & Defence | **B** Protection / Defence |
| CONTROL / MANIPULATION | Strategy & Management | **C** Strategic Management |
| DOMINATION / OPPRESSION | Power & Dominance | **D** Power Mobilisation |

The artwork's names survived for A and B. The written layer's names survived for
C and D.

**Three Positions have no ancestor in the visual layer at all:** X Baseline,
A↔B Safety Checking, Z Shutdown. Shutdown is the notable one — Map 1 already
names the Dorsal Vagal State in its polyvagal panel, so the biology was in the
first diagram from the start. It only became a Position in Engine 2, on
2026-07-27.

## F-layer correspondence

The twelve written frameworks in
`teg-blue-legacy/teg-blue-back-to-origins/teg-blue-vault-origin-bf8f641-2026-04-20/frameworks/`
line up with the eleven maps almost one to one.

| F | Written framework | Map |
| --- | --- | --- |
| F1 | The Emotional Gradient | 1 |
| F2 | Developmental Calibration | 2 |
| F3 | Adult Cognition and False Coherence | 3 |
| F4 | Rules Regulate | 4 |
| F5 | Worth Hierarchies Regulate | 5 |
| F6 | Bias Regulates | 6 |
| F7 | Domination Regulates | 7 |
| F8 | Awareness Rebuilds Through Safety | 8 |
| F9 | Variation Is Configuration | 9 |
| F10 | What The Adult Processes | 10 — **weak match** |
| F11 | Paradox Holds What Logic Cannot | 11 |
| F12 | Two Information Systems | **none** |

**Confirmed 2026-08-02 by Anna's own filenames.** `old-diagrams-reference/` names
them `01-F1 - Map 1`, `02-F2 - Map 2`, `03-F3 - Map 3`, `04-F7 - Map 7`. The
correspondence is stated, not inferred — for those four. The rest still rest on
titles, and F10↔10 remains weak: "What The Adult Processes" and "Rebuilding
Generational Bridges" are not obviously the same subject.

The maps came first. Artwork November–December 2025; the written frameworks from
2026-04-11. So the F-layer is the write-up of the maps, not the other way round.

If the correspondence holds, the F-layer is the written form of the MetaMap and
the two are one artefact in two media. That is worth confirming before either is
edited again, because editing one and not the other is how they drift.

### The empathy sensors — a component, not a detail

Cognitive empathy, emotional empathy, empathic concern appear inside Map 2 and
again inside Map 7. In the Circuit Board they are broken out as their own module,
wired between Maps 1/7 and Maps 4/6.

That promotion — from a panel inside two maps to a standalone component with
inputs and outputs — is the clearest single piece of evidence that the structure
was becoming a system rather than a sequence.

### The 4-Mode set

Three diagrams in one generation, in a different format from Maps 1–7: landscape,
built on a ruler with tick marks and a slider.

- **The 4-Mode Gradient** — Connection/Belonging, Protection/Defense,
  Control/Manipulation, Domination/Oppression.
- **Four Modes Gradient Full Breakdown** — the same four across Brain/Body,
  Neurochemistry, Emotional Connection, Empathy; then ten emotions; then twelve
  values (Power, Virtue/Obedience, Gender Roles, Success, Love, Goodness,
  Provider Role, Silence/Confrontation, Emotion Expression, Belonging, Progress,
  Truth).
- **The Glyph Library** — the same emotion drawn four times, once per mode.
